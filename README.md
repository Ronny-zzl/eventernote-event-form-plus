# Eventernote イベント登録エンハンサー

[イベンターノート](https://www.eventernote.com/) のイベント登録画面・編集画面を使いやすくするユーザースクリプトです。

[中文说明](#中文说明)

## インストール

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストールします
2. [こちら](https://github.com/Ronny-zzl/eventernote-event-form-plus/raw/main/eventernote-event-form-plus.user.js) を開き、Tampermonkey の画面で「インストール」を押します

## 機能

### 告知文から入力

告知文を貼り付けると、開催日と開場・開演・終演の時間をまとめて入力します。

- 日付：`2026年12月19日(土)`、`12/19（土）`、`12月19日` など。年が書かれていない場合は曜日から年を判断します
- 時間：`開場 17:30 / 開演 18:30`、`開場/開演 17:30/18:30`、`OPEN/START…18:20/18:50`、`17:30開場` など
- 「販売開始」「受付終了」など、イベントの時間ではないものは読み取りません

### 開催日

年・月・日の 3 つのプルダウンの代わりに、カレンダーから日付を選べます。曜日も表示されます。

### 時間入力

- 開場・開演・終演の時間を、6 つのプルダウンの代わりにテキスト欄で入力できます。`1830`、`18:30`、`18時半`、`午後6時半`、`6:30pm` などの書き方に対応し、全角数字も使えます
- 1 分単位で入力できます（`18:29` など）
- 「開演の30分前」「開演の2時間後」などのボタンで開場・終演時間を素早く設定できます
- `25:30` は `01:30` に変換され、日付をまたぐ時間には「翌日」と表示されます
- 編集画面では、1 分単位で登録された時間も正しく読み込みます

### 出演者

- **検索**：頭文字のプルダウン（「あ」だけで 6000 人以上）の代わりに、名前やよみがなで検索して追加できます。名前・よみがなの一致度とお気に入り数の順に並び、選んだ後もリストが閉じないので、グループとメンバーを続けて追加できます。最近追加した出演者も表示されます
- **まとめて追加**：「 / 」や改行で区切られた出演者の名簿を貼り付けると、全員を一度に検索して追加できます。名前が一致した人は自動でチェックされ、同名の人や候補しか見つからなかった人は自分で選べます（見つからなかった人は登録ページへのリンクと、語を変えて再検索する欄が出ます）
- **並び替え**：☰ のドラッグ、または ▲▼ ボタンで並び替えられます。登録・編集時はこの順番で送信されます
- **複数選択**：チェックボックスで複数選び（Shift で範囲選択）、まとめて移動・ドラッグ・削除できます
- **出演者セット**：グループとメンバー全員など、よく使う組み合わせを保存し、ワンクリックでまとめて追加できます。セットの先頭（グループ名など）が既にリストにある場合、メンバーはその直後に追加されます。初めて使うときは例として「前橋ウィッチーズ」のセットが入っています

### 開催場所

都道府県と会場のプルダウン（東京都だけで 6000 件以上）の代わりに、会場名や住所で検索して選べます。都道府県で絞り込むこともでき、閉館した会場は最後に表示されます。最近使った会場も表示されます。編集画面では現在の会場がすぐに表示されます。

### 送信前のチェック

イベント名・出演者・開催場所が未入力のときや、検索欄に入力したまま選んでいない文字があるときに、送信前に確認します。

### 入力内容の自動保存

登録画面の入力内容を自動で保存します。タブを閉じてしまっても、次に登録画面を開いたときに復元できます（サムネイル画像は保存されません）。

### 確認画面から戻る

確認画面に「戻って修正する」ボタンを追加します。登録画面に戻ると、出演者・会場・サムネイル画像を含め入力内容がすべて復元されます。

### サムネイル画像

- **登録画面**：画像をドラッグ＆ドロップ、Ctrl+V で貼り付け、またはクリックしてファイルを選択できます。登録画面には本来画像欄がないため、登録完了後にイベント編集機能を使って自動でアップロードします（イベント名と会場が一致することを確認してから送信します。編集履歴に自分の編集が 1 件記録されます）。関連リンクがある場合、サイトがリンク先から画像を自動生成するため、それが終わるのを待ってからアップロードします（通常 5〜10 秒、完了画面を開いたままお待ちください）。
- **編集画面**：画像欄が同じ操作に対応し、現在の画像と新しい画像を並べて確認できます。

## データについて

出演者セットや入力内容の一時保存は、すべてお使いのブラウザの Tampermonkey 内に保存されます。外部のサーバーには送信しません。

## 開発

TypeScript で書かれており、[Vite](https://vite.dev/) + [vite-plugin-monkey](https://github.com/lisonge/vite-plugin-monkey) でビルドしています。`src/` を編集し、`pnpm build` でリポジトリ直下の `eventernote-event-form-plus.user.js` を生成してください（このファイルは直接編集しません）。

```sh
pnpm install
pnpm dev          # 開発サーバー（Tampermonkey に開発版を入れると自動で更新）
pnpm build        # eventernote-event-form-plus.user.js を生成
pnpm test         # 単体テスト
pnpm site login   # e2e テスト用にログイン（Chrome が開きます）
pnpm test:e2e     # 実際のページを使ったテスト
pnpm preview:serve # テスト版をビルドして LAN に公開（スマートフォンで http://PCのIP:4173/eventernote-event-form-plus.preview.user.js を開いてインストール）
```

## 中文说明

改善 [Eventernote](https://www.eventernote.com/) 活动登录页和编辑页的 Tampermonkey 用户脚本。

**安装**：安装 [Tampermonkey](https://www.tampermonkey.net/) 后，打开[这个链接](https://github.com/Ronny-zzl/eventernote-event-form-plus/raw/main/eventernote-event-form-plus.user.js)并点击「安装」。

**功能**：

- **从告知文输入**：粘贴告知文，开催日和开场 / 开演 / 终演时间一起填好。日期支持 `2026年12月19日(土)`、`12/19（土）` 等（没写年份时按星期推断），时间支持 `開場 17:30 / 開演 18:30`、`OPEN/START…18:20/18:50`、`17:30開場` 等；不会误读「販売開始」「受付終了」
- **开催日**：用日历选择日期，代替年 / 月 / 日三个下拉框，并显示星期
- **时间输入**：用文本框代替 6 个下拉框，识别 `1830`、`18:30`、`18時半`、`午後6時半`、`6:30pm` 等写法；支持 1 分钟单位；「開演の30分前」「開演の2時間後」等快捷按钮；`25:30` 自动转为 `01:30` 并标记「翌日」
- **出演者**：
  - 搜索：用名字或读音搜索添加，代替头文字下拉框（「あ」就有 6000 多人）；按一致度和收藏人数排序，选中后列表不关闭，可以连续添加团体和成员；显示最近添加的出演者
  - 批量添加：粘贴用「 / 」或换行分隔的出演者名单，一次搜索并添加全部；名字一致的自动勾选，同名或只有候选的自己选择（找不到的显示登记链接和改词重搜的输入框）
  - 排序：拖动 ☰ 或用 ▲▼ 调整顺序，提交时按此顺序发送
  - 多选：用复选框选中多人（Shift 选范围），一起移动、拖动或删除
  - 出演者组合：把常用组合（如团体 + 全体成员）保存下来一键添加；列表里已有组合的第一项时，成员插在它后面；初次使用时带一个示例组合「前橋ウィッチーズ」
- **开催场所**：用会场名或地址搜索，代替都道府県 + 会场下拉框（东京都就有 6000 多个）；可按都道府県筛选，已闭馆的排在最后；显示最近使用的会场；编辑页立即显示当前会场
- **提交前检查**：活动名、出演者、会场未填，或搜索框里留着没选中的文字时，提交前提示确认
- **自动保存草稿**：登录页的内容自动保存，误关页面后下次打开登录页可以恢复（不含缩略图）
- **从确认页返回修改**：确认页增加「戻って修正する」按钮，返回后恢复全部内容（包括出演者、会场和缩略图）
- **缩略图**：登录页可以拖入、Ctrl+V 粘贴或选择文件添加图片；登录完成后通过活动编辑功能自动上传（会先核对活动名和会场，编辑历史中会多一条自己的记录）；有关联链接时，网站会根据链接自动生成图片，脚本会等它完成后再上传（通常 5〜10 秒，请保持完成页打开）。编辑页的图片字段同样支持这些操作，并显示新旧图片对比

所有数据只保存在浏览器的 Tampermonkey 存储中，不会发送到第三方服务器。

**开发**：源码是 `src/` 下的 TypeScript，用 Vite + vite-plugin-monkey 构建；根目录的 `eventernote-event-form-plus.user.js` 是构建产物，不要直接修改。常用命令见上面的「開発」一节。
