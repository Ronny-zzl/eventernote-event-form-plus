# Eventernote イベント登録エンハンサー

[イベンターノート](https://www.eventernote.com/) のイベント登録画面・編集画面を使いやすくするユーザースクリプトです。

[中文说明](#中文说明)

## インストール

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストールします
2. [こちら](https://github.com/Ronny-zzl/eventernote-enhancer/raw/main/eventernote-add-enhancer.user.js) を開き、Tampermonkey の画面で「インストール」を押します

## 機能

### 出演者の並び替え

選択済みの出演者を ☰ のドラッグ、または ▲▼ ボタンで並び替えられます。登録時はこの順番で送信されます。

### 出演者セット

グループとメンバー全員など、よく使う出演者の組み合わせを「出演者セット」として保存し、ワンクリックでまとめて追加できます。

### 確認画面から戻る

確認画面に「戻って修正する」ボタンを追加します。登録画面に戻ると、出演者や会場を含め入力内容がすべて復元されます。

### サムネイル画像

- **登録画面**：画像をドラッグ＆ドロップ、Ctrl+V で貼り付け、またはクリックしてファイルを選択できます。登録画面には本来画像欄がないため、登録完了後にイベント編集機能を使って自動でアップロードします（イベント名と会場が一致することを確認してから送信します。編集履歴に自分の編集が 1 件記録されます）。
- **編集画面**：画像欄が同じ操作に対応し、現在の画像と新しい画像を並べて確認できます。

## データについて

出演者セットや入力内容の一時保存は、すべてお使いのブラウザの Tampermonkey 内に保存されます。外部のサーバーには送信しません。

## 中文说明

改善 [Eventernote](https://www.eventernote.com/) 活动登录页和编辑页的 Tampermonkey 用户脚本。

**安装**：安装 [Tampermonkey](https://www.tampermonkey.net/) 后，打开[这个链接](https://github.com/Ronny-zzl/eventernote-enhancer/raw/main/eventernote-add-enhancer.user.js)并点击「安装」。

**功能**：

- **出演者排序**：已选择的出演者可以拖动（☰）或用 ▲▼ 调整顺序，提交时按此顺序发送
- **出演者组合**：把已选的出演者（如团体 + 全体成员）保存为组合，之后一键全部添加
- **从确认页返回修改**：确认页增加「戻って修正する」按钮，返回登录页时恢复全部已填内容（包括出演者和会场）
- **缩略图**：登录页可以拖入、Ctrl+V 粘贴或选择文件添加图片；登录完成后通过活动编辑功能自动上传（会先核对活动名和会场，编辑历史中会多一条自己的记录）
- **编辑页图片**：活动编辑页的图片字段同样支持拖入、粘贴和选择文件，并显示新旧图片对比

所有数据只保存在浏览器的 Tampermonkey 存储中，不会发送到第三方服务器。
